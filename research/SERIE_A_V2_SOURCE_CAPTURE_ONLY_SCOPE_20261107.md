# MARKET_ANCHOR_1X2_V2 — private source-only capture scope

Date: 2026-11-07
Scope: original frozen V2 source preservation only; no inference or model change.

## Provider wording and project boundary

The official Football-Data fair-use page says its free CSV/Excel data are intended for private individuals' personal betting and/or academic interest and research, with manual downloads or at most two light automated download sessions per week. It excludes commercial and AI data-training projects.

The project now separates two operations:

1. Source-only archival/validation: permitted internally under the stated private/noncommercial research-use wording, subject to a private GitHub repository, the shared two-session rolling-seven-day budget, source SHA checks, and the preregistered 30-primary-completed-event identity gate before parsing current-season completed rows.
2. Frozen-model inference: remains blocked. The public page does not separately define applying the already-frozen V2 weights to these data. No inference permission is inferred from the source-capture allowance.

This is a narrow project scope classification based on the public research-use wording, not a provider-issued licence or a legal opinion. It does not authorize feature construction, model inference, AI training, commercial use, public product publication, or redistribution.

## Runtime contract

- research_source_capture_permitted=true is a source-only project flag.
- research_inference_permitted=false and provider_issued_ai_inference_license=false remain binding.
- The source-capture workflow must pass both the source-only rights gate and a read-only private-repository check before Supabase metadata, provider CSV, download-budget markers, or artifact upload.
- The current-season CSV is not requested or parsed until at least 30 unique primary completed-event identities have been confirmed using only match_date, home_team, and away_team.
- Captured rows are retained only as lagged historical source material; no V2 probabilities or forecasts are generated by this workflow.
- The separate evaluation gate remains 30 eligible completed prospective forecasts. It is still closed; no target outcomes may be read for evaluation before that gate.
- The original candidate, 19-feature order, weights, scaler/imputer, active_lambda=0, and shadow_lambda=1 are unchanged.

## Explicit non-results

No live source request, quote read, inference, target-outcome evaluation, paid provider call, Supabase write/DDL, production artifact change, or model promotion is authorized by this scope note. The current repository is public, so the private-storage gate blocks live source capture until the repository is made private through a separate owner action.
